# Fieldnotes — Flexbox Landing Page

A responsive outdoor-gear landing page created for the Day 7 / Week 7 Flexbox assignment. The page brings together a navigation bar, hero section, product listing, pricing cards, and login form in one polished layout.

## Student repository setup

Create your assignment repository using this exact naming pattern:

```text
<rollno>-<firstname>-webdev-day07-flexbox-landing
```

Replace `<rollno>` with your student roll number and `<firstname>` with your first name, in lowercase. For example:

```text
23-Shaurya-webdev-day07-flexbox-landing
```

Create the repository on GitHub, clone it to your computer, and add the project files to the repository. Keep `index.html` at the project root so it is easy to open and review.

## Project requirements

Build a responsive landing-page section that demonstrates the Flexbox concepts covered in class:

- A horizontal navbar with a responsive menu.
- A hero section with clear heading, supporting copy, and call to action.
- A wrapping product-card listing using `flex-wrap`, `flex-grow`, and `flex-basis`.
- Pricing cards and a centred login form using `justify-content` and `align-items`.
- A layout that adapts to both desktop and mobile screen widths.

This example adds product imagery, membership details, and small interactions as extra polish. The login form is a front-end demo and does not authenticate users or store data.

## Run the project

Open `index.html` in a web browser. No build tools or dependencies are required. Product photos load from Unsplash, so an internet connection is needed to display them.

## Suggested workflow

1. Create and clone your GitHub repository using the naming format above.

5. Submit the repository link and a screenshot of the finished page.

## Flexbox concepts used

- `display: flex` aligns and distributes items in the navbar, hero, and other sections.
- `justify-content` and `align-items` control spacing and cross-axis alignment.
- `flex-wrap` lets product cards, pricing cards, and other groups reflow onto new lines.
- `flex-grow` and `flex-basis` let cards share available space while keeping a useful minimum width.
